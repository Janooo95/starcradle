Privacy Policy

Last updated: November 8, 2026

This policy covers the YouTube channel Starcradle and the application “Einschlafkanal Upload”, a private desktop tool used only by the owner of the Starcradle channel to upload and manage videos on that channel.

Use of YouTube API Services

Einschlafkanal Upload uses the YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the application

The application is not offered to the public. The only account that signs in is the Google account that owns the Starcradle channel. It does not collect data from viewers or other users.

What data is accessed

  • Information about the owner's own channel and videos (titles, descriptions, upload and processing status, playlists, thumbnails).
  • Statistics of the owner's own channel and videos (e.g. views, watch time, subscribers) via the YouTube Analytics API.
  • Public search results for a few keywords per week, from which only aggregated values (e.g. typical video lengths, common title words) are derived.

How data is used

The data is used only to upload the owner's videos, check that uploads were processed correctly, show statistics in a local dashboard and plan future videos. It is not used for advertising and is not sold.

Storage, sharing and deletion

All data is stored locally on the owner's own computer. It is not shared with or transferred to third parties. Statistics are refreshed regularly; aggregated search results are overwritten weekly, and no API data is kept for more than 30 days without being refreshed. The OAuth access token is stored locally and can be revoked at any time via the Google security settings page; revoking it stops all access, and the locally stored data can then be deleted.

Cookies

This website and the application do not use cookies or tracking.
